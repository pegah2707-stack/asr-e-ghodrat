# عصر قدرت — سیستم مالکیت مرکزی

این نسخه برای استفاده چندنفره طراحی شده است و برخلاف فایل HTML آفلاین، اطلاعات بازی را روی سرور و PostgreSQL نگه می‌دارد.

## ساختار دسترسی
- AMIR = OWNER و تنها مالک سیستم.
- حداکثر ۲ حساب ADMIN.
- OWNER تنها کسی است که می‌تواند ADMIN بسازد، حذف کند، فعال/غیرفعال کند، رمز را عوض کند و تاریخ پایان دسترسی تعیین کند.
- ADMIN به مدیریت بازیکنان، تجهیزات، گزارش خرید و درآمد روزانه دسترسی دارد، اما به مدیریت مالک/ادمین‌ها و سیزن دسترسی مالکانه ندارد.
- PLAYER فقط حساب و بازی خودش را مدیریت می‌کند.

## سیزن
- OWNER می‌تواند سیزن جدید بسازد.
- یک سیزن را فعال کند.
- سیزن فعال را پایان دهد.
- خریدها و درآمد روزانه به سیزن فعال متصل می‌شوند.

## کنترل بازیکن
- بازیکن جدید: ۲ میلیارد دلار و ۰ نفت.
- انتخاب کشور فقط یک‌بار و هر کشور فقط برای یک بازیکن.
- OWNER/ADMIN می‌توانند پول و نفت بازیکن را تغییر دهند.
- OWNER/ADMIN می‌توانند مستقیم به انبار بازیکن تجهیز اضافه یا از آن کم کنند.

## خرید و گزارش
هر خرید روی سرور ثبت می‌شود و یک `purchase_report` ایجاد می‌کند. مالک/ادمین در پنل مدیریت گزارش خریدها را می‌بینند؛ نیازی نیست بازیکن گزارش را دستی ارسال کند.

## درآمد روزانه
هر روز ساعت ۰۰:۰۰ بر اساس `APP_TIMEZONE` اجرا می‌شود. بازیکنی که حداقل ۵٬۰۰۰٬۰۰۰ نفت داشته باشد، ۵ میلیون نفت مصرف می‌کند و ۱ میلیارد دلار می‌گیرد. اجرای همان روز دوباره پرداخت نمی‌کند.

## راه‌اندازی
1. PostgreSQL بسازید و `DATABASE_URL` را تنظیم کنید.
2. `.env.example` را به `.env` تبدیل کنید و رمزهای قوی برای OWNER و دو ADMIN قرار دهید.
3. `npm install`
4. `npm run seed`
5. `npm start`
6. برنامه از آدرس سرور روی پورت `PORT` در دسترس است.

**نکته امنیتی:** رمزهای واقعی را داخل کد، GitHub یا فایل قابل دانلود بازیکنان قرار ندهید. آن‌ها را فقط در Secret/Environment Variables سرویس سرور نگه دارید.
